# ani365-cli

POSIX shell-клиент для поиска и просмотра аниме через API Anime365.
Проект основан на [ani-cli](https://github.com/pystardust/ani-cli) версии 5.0.2
и распространяется по лицензии GPL-3.0-or-later.

## Требования

- `curl`, `jq` и программа для интерактивного меню: `fzf`, `rofi` или `dmenu`;
- `mpv` для воспроизведения по умолчанию, `vlc` при использовании `--vlc` или
  `yt-dlp` для загрузки;
- аккаунт Anime365 с активной подпиской для получения ссылок на видео.

## Установка

### Windows 11 через Scoop

```powershell
scoop bucket add ani365-cli https://github.com/DrumDrumSpike/ani365-cli.git
scoop install ani365-cli
```

Scoop автоматически установит Git Bash, `jq`, `fzf` и `mpv`. После установки
команда `ani365-cli` доступна из PowerShell, CMD и Windows Terminal. Сам клиент
выполняется внутри Git Bash через поставляемую обёртку `ani365-cli.cmd`.

Обновление и удаление выполняются стандартными командами:

```powershell
scoop update ani365-cli
scoop uninstall ani365-cli
```

Манифест Scoop загружает файлы из ветки `main`, поэтому новые контрольные суммы
должны публиковаться вместе с каждым изменением исполняемых файлов.

### Linux и WSL

```sh
install -Dm755 ani365-cli "$HOME/.local/bin/ani365-cli"
```

Скрипт также работает в Git Bash и WSL, если необходимые зависимости доступны
через `PATH`. Основная поддерживаемая среда — Linux с mpv.

## Авторизация

Создайте API-клиент на сайте Anime365 и получите токен доступа через браузер.
Затем сохраните и проверьте его, не добавляя токен в историю команд оболочки:

```sh
ani365-cli --auth
```

Токен сохраняется с маской прав процесса `077`. По умолчанию используется файл
`$XDG_CONFIG_HOME/ani365-cli/access_token` или
`~/.config/ani365-cli/access_token`. Удалить локальный токен можно командой
`ani365-cli --logout`. Токены никогда не принимаются через аргументы командной
строки.

## Примеры

```sh
ani365-cli "Стальной алхимик"
ani365-cli --dub --lang ru -q 1080 "Ковбой Бибоп"
ani365-cli -e 1-3 --translation "Студия" "Название"
ani365-cli --continue
ani365-cli --download -e 1 "Название"
```

Полный список параметров доступен через `ani365-cli --help`. Для настройки
также используются перечисленные в справке переменные окружения `ANI365_*`.
История и конфигурация хранятся отдельно от оригинального ani-cli.

## Особенности API

OpenAPI-схема не определяет точную структуру ответа embed. Клиент поддерживает
поля `data.stream` и `data.streams`, варианты `urls`, `urlList` и `url`, а также
внешние субтитры из `subtitlesUrl`. Если структура рабочего API изменится,
достаточно обновить единственную точку совместимости — функцию `get_streams()`.

Проект не связан официально с Anime365 или разработчиками исходного ani-cli.
