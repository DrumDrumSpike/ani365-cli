# Персональные рекомендации

## Цель

Раз в неделю формировать для каждого разрешённого пользователя Mini App ленту
Anime365-рекомендаций из его оценок Shikimori и жанров. Первый релиз использует
только завершённые тайтлы с оценкой: нужно не менее пяти.

## Развёртывание

Рекомендатор запускается на том же VDS, что и основной бот. Это отдельный
одноразовый Docker Compose service с лимитами `0.5 CPU` и `256 MiB RAM`, который
вызывает systemd timer. Он не открывает сетевой порт, не использует Telegram Bot
API, не скачивает медиа и завершается после расчёта.

```text
Shikimori GraphQL -> recommender -> private Docker API web -> bot.sqlite3
                                                        -> Mini App feed
```

`recommender` обращается к `http://web:8000` только внутри Docker network и
аутентифицируется значением `RECOMMENDER_SHARED_SECRET`. У него нет volume с
`bot.sqlite3`, `token.key` или `.env`-токенами, кроме выделенного секрета.

## Данные и алгоритм

Миграция SQLite v12 добавляет `external_user_rates.score` и таблицу
`recommendation_items`. В неё попадают только публичные карточки, итоговый балл,
объяснение и дата генерации; OAuth-токены не копируются.

1. Импорт Shikimori сохраняет оценку от 1 до 10. Ноль означает «без оценки».
2. Завершённые тайтлы с 7–10 усиливают их жанры, 1–4 ослабляют, 5–6 нейтральны.
3. Рекомендатор читает публичные metadata и кандидатов Shikimori по сильнейшим
   жанрам, ограничивая общий пул восемью жанрами по двадцать тайтлов.
4. Каждый кандидат должен быть подтверждён точным Anime365 MAL ID. Названия не
   сопоставляются автоматически.
5. Исключаются любые тайтлы из списка Shikimori и локальной библиотеки. Лента
   сортируется по жанровой близости и общей оценке Shikimori.
6. Готовая лента заменяется одной SQLite-транзакцией. Ошибка задачи не удаляет
   прошлую удачную ленту.

## Контракты

Внутренние пути не публикуются Caddy и требуют `X-Recommender-Token`:

- `GET /internal/recommendations/profiles` — обезличенный от секретов профиль;
- `POST /internal/recommendations/resolve` — точная проверка кандидатов в Anime365;
- `PUT /internal/recommendations/{user_id}` — запись готовой выдачи.

Mini App читает только `GET /api/recommendations`, защищённый обычной Telegram
авторизацией. Пользователь видит карточку, причину и время последнего обновления.

## Проверки

Тесты покрывают миграцию и импорт оценок, изоляцию внутреннего API, сохранение
ленты, отсутствие OAuth-токенов в его ответах, фильтрацию и ранжирование. Перед
обновлением VDS запускаются полный `unittest`, Docker build и `docker compose
config --quiet`.
